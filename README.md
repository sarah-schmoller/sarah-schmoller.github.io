### About Me

I'm a software engineer specializing in AI-powered content generation, natural language generation (NLG), and scalable cloud-based systems.

I currently work as a Lead Software Engineer at Dow Jones, where I've helped design and build systems that automate the creation and publication of hundreds of articles daily across publications including MarketWatch and Barron's.

I'm particularly interested in the intersection of software engineering, artificial intelligence, and storytelling, from automated journalism to interactive characters and immersive experiences.

I write software that tells stories.
